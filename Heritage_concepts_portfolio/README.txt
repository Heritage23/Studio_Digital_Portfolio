# Studio Digital Portfolio

This is a starter portfolio for an AI product-content + website service.

## Open it
Double-click `index.html` to view it in your browser.

## Before publishing
1. Replace the placeholder WhatsApp link in `index.html` with your own WhatsApp link.
2. Replace the "Beauty & Hair", "Food & Lifestyle", and "Business Websites" coming-soon cards with real projects as you create them.
3. Add your own name/brand in the logo if you want.
4. Do not claim the sample project is paid client work; it is a portfolio concept.

## Files
- `index.html` — portfolio page
- `style.css` — styling
- `assets/turmeric-before.jpg` — original uploaded photo
- `assets/turmeric-after.png` — styled portfolio image
